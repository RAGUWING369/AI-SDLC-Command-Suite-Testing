aria-live="polite": Error region uses aria-live="polite" so screen readers announce the error after any ongoing announcement completes (WCAG 4.1.3). Does not interrupt current reading.
Focus management: On retry failure, focus returns to the Retry button (autofocus / ref.focus()) so keyboard users can immediately retry without tabbing through the page again (WCAG 2.4.3).
Retry logic: Exponential backoff — first retry immediately, second after 2s, third after 5s. After 3 retries, shows "Still having trouble?" with a support email link. Prevents hammering the API during outage.
