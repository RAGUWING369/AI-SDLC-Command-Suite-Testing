🔒

This tracking link is invalid or expired

The link you followed may have expired or the order ID is incorrect.

If you have an account, sign in to view all your orders.

Tracking links are valid for 90 days from order placement date.

Invalid token: Backend returns HTTP 404 (not 200 with error body) to prevent token enumeration. role="alert" on the error container ensures screen readers announce the error state immediately (WCAG 4.1.3).
Token security: HMAC-SHA256 token uses order UUID + secret key. Tokens are not stored in DB — validated on the fly. 90-day expiry enforced server-side by checking order.created_at.
