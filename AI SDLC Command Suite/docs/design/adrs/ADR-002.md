# ADR-002: Technology Stack Selection

**Status:** Accepted
**Date:** 2026-05-14
**Deciders:** Full-stack Lead, Backend Developer, Frontend Developer

---

## Context

The technology stack was established in CLAUDE.md before Phase 4 and confirmed by stakeholder approval of Phases 1–3. This ADR formally records the justification for each major technology selection, the alternatives considered, and the reasons they were rejected — making the decision traceable and auditable for all downstream phases.

The stack must satisfy:
- CON-001: $2,000/month AWS budget at 100-seller MVP scale
- CON-002: MVP delivery by 2026-10-31
- CON-003: 3 developers (no dedicated DevOps)
- CON-005: Razorpay exclusively for payments (India-native)
- CON-007: Django monolith (no microservices)
- NFR-PE-001: API P95 < 200ms
- NFR-PE-002: LCP < 2.5s mobile
- NFR-SEC-007: Zero card data stored (PCI-DSS delegation)
- NFR-MAINT-001/002: ≥80% test coverage (backend + frontend)

## Rationale

**Next.js 14 (App Router):** SSR is mandatory for product/category pages (SEO — buyers must find ShopNest products on Google). Next.js 14 App Router supports React Server Components and streaming SSR, enabling LCP < 2.5s even on mobile 4G (NFR-PE-002) by delivering server-rendered HTML before client JS loads. CSR is used for cart, checkout, and seller dashboard (auth-gated, interactivity required, not SEO-critical).

**Django 5.x + DRF 3.15:** CLAUDE.md specifies Django. DRF is the canonical REST framework for Django. Django's batteries-included ORM, migrations, admin, signals, and middleware allow 3 developers to cover 68 FRs without building infrastructure from scratch. Gunicorn 4w×4t provides 16 concurrent request slots per container — sufficient for 100 req/s steady-state with 2 ECS tasks.

**Celery 5.x + Redis broker:** Weekly payout cron (BR-006), async email dispatch (NFR-REL-006), async analytics writes, and async audit log writes all require an async task queue. Celery + Redis is the de facto standard for Django async; it handles the weekly payout Celery Beat job without Lambda's 15-minute execution limit.

**Razorpay:** CON-005 — India-only payment gateway supporting UPI (dominant in India), cards, NetBanking, and EMI. Razorpay Subscriptions API manages seller recurring billing. Razorpay Payouts API handles weekly bank transfers. No card data touches ShopNest servers (NFR-SEC-007, PCI-DSS delegation).

**AWS stack (ECS Fargate, RDS, ElastiCache, S3, CloudFront, SES):** AWS is the declared cloud provider (CLAUDE.md). All services are available in ap-south-1 (Mumbai) for India data residency (DPDPA 2023 compliance). ECS Fargate eliminates EC2 management (NFR-PORT-002). RDS PostgreSQL with Multi-AZ satisfies NFR-REL-001 (99.9% uptime) and NFR-REL-003 (RPO < 1h). ElastiCache Redis for cart TTL and caching. CloudFront for image CDN (NFR-PE-004). SES for transactional email (NFR-REL-006).

## Alternatives Considered

| Component | Alternative | Why Rejected |
|-----------|------------|-------------|
| Next.js | Nuxt.js (Vue) | No team Vue proficiency; 4-week context switch cost |
| Next.js | Remix | Smaller ecosystem; less Razorpay integration support |
| Django | FastAPI | No ORM, migrations, or admin panel — 3× more setup code |
| Django | Node.js/Express | Team is Python-proficient; splitting backend language adds cognitive overhead |
| PostgreSQL | MySQL 8 | Inferior FTS; JSONB not natively available; UUID support less mature |
| Redis | Memcached | Cannot serve as Celery broker; no rich data types |
| Celery | AWS SQS + Lambda | Lambda 15-min limit blocks payout job; cold starts violate P95 NFR |
| CloudFront | Cloudflare | Not AWS-native; additional DNS management |
| AWS SES | SendGrid | $15–50/month additional cost; not AWS-native |
| ECS Fargate | EKS Kubernetes | $200+/month cluster cost; 3-person team can't sustain Kubernetes ops |
| GitHub Actions | CircleCI | Additional account; GitHub Actions covers all CI needs |

---

## Consequences

**Positive:**
- Stack is consistent with team's declared skills — zero ramp-up time
- All AWS services in ap-south-1 satisfy DPDPA data localization requirement
- Razorpay handles all payment complexity including PCI-DSS scope
- SSR/CSR hybrid in Next.js optimally serves SEO and interactivity requirements simultaneously

**Negative (accepted):**
- Python/Django is slower than Go/Rust for raw throughput — acceptable at MVP scale with ECS auto-scaling
- Next.js App Router is relatively new (GA 2023) — some ecosystem gaps vs. Pages Router; mitigated by using only stable features
- ECS Fargate cold start (~10s) affects very first request after scale-out — mitigated by ALB health checks and pre-warming min 2 tasks
